# 🌸 EsteticMe | Gestión Inteligente para Centros de Estética

![Estado del Proyecto](https://img.shields.io/badge/Estado-Finalizado-success?style=for-the-badge)
![Tecnologías](https://img.shields.io/badge/Stack-Django_%7C_React-blueviolet?style=for-the-badge)

**EsteticMe** es una plataforma integral diseñada para digitalizar la relación entre profesionales de la belleza y sus clientes. Bajo una estética minimalista, el sistema combina una robusta gestión de citas (Backend) con una experiencia de usuario fluida y reactiva (Frontend).

---

## ✨ Características Principales

### 💼 Para el Profesional
* **Calendario Dinámico:** Visualización semanal de citas con alineación milimétrica y gestión de estados (Confirmada, Terminada, Cancelada).
* **Gestión de Negocio:** Panel para editar información del salón y galería de fotos interactiva.
* **Catálogo de Servicios:** CRUD completo de tratamientos con subida de imágenes reales.
* **Control de Disponibilidad:** Configuración flexible de horarios de apertura y cierre por día.

### 🧖 Para el Cliente
* **Buscador Inteligente:** Filtrado de servicios por categorías y salones.
* **Sistema VIP (Fidelización):** Acumulación de puntos por cada servicio realizado y canje dinámico durante el checkout.
* **Reserva en Tiempo Real:** Interfaz paso a paso para agendar citas evitando solapamientos.

### 🛡️ Calidad Técnica
* **UX Adaptativa:** Favicon dinámico (Dark/Light mode) y enrutado seguro (Rutas Protegidas).
* **Robustez:** Página de error 404 personalizada y validación de datos en servidor.

---

## 🛠️ Stack Tecnológico

**Backend:**
* Python 3.x & **Django**
* Django REST Framework (API REST)
* JWT para autenticación segura.
* Pillow (Procesamiento de imágenes).

**Frontend:**
* **React** (Hooks, Context)
* React Router DOM (Navegación SPA)
* **Tailwind CSS** (Diseño "Aura")
* Material Symbols (Iconografía)

## 🚀 Instalación y Uso

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/MoralesMacarena/esteticme.git
    ```

2.  **Configurar Backend:**
    ```bash
    cd backend
    pip install -r requirements.txt
    python manage.py migrate
    python manage.py runserver
    ```

3.  **Configurar Frontend:**
    ```bash
    cd frontend
    npm install
    npm start
    ```
